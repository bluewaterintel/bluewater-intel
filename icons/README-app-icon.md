# iOS app icon (home screen tile)

Xcode hides this — the fastest path:

1. Save your logo as **`icons/app-icon-1024.png`**
   - Exactly **1024 × 1024** pixels
   - **PNG**, no transparency
   - Square marlin/symbol on brand teal `#0d9488` (not the wide wordmark).
     Teal is deliberate: a navy tile disappears against dark wallpapers.

2. Run from the repo root:

   ```bash
   npm run ios:icon
   npm run cap:sync
   ```

3. In Xcode: **Product → Clean Build Folder** (`Cmd+Shift+K`), then **Run**.

The file is copied to:
`ios/App/App/Assets.xcassets/AppIcon.appiconset/AppIcon-512@2x.png`

## Launch splash (separate asset — do not reuse the icon)

`ios/App/App/Assets.xcassets/Splash.imageset/splash-2732x2732*.png` is **not**
generated by `npm run ios:icon`.

iOS draws the launch image with `scaleAspectFill`, so a tall phone scales the
2732 square to cover the height and crops to roughly the middle **46%** of its
width. Dropping the full-bleed app icon in here comes out zoomed and clipped.

The committed splash is the marlin at ~950 px wide, centred on the app
background navy `#0a1628` — inside the safe band, and the same navy the app
paints on boot so there is no colour flash. Keep the splash navy even though the
icon is teal; the app body is navy, and a teal splash would flash on hand-off.

## Optional: set in Xcode

Open **`ios/App/App.xcworkspace`** → left sidebar **App** (yellow folder) → **Assets.xcassets** → **AppIcon** → drag PNG onto the **1024×1024** slot labeled *App Store iOS*.
