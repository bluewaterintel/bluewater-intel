## Dashboard checklist (blocking publish)

Open **Dashboard** in Play Console and complete every item with a warning. Typical first-time list:

| Task | Where | What to enter |
|------|--------|----------------|
| **Privacy policy** | App content → Privacy policy | `https://app.bluewaterintel.com/privacy.html` |
| **App access** | App content → App access | All functionality available after sign-in; no special credentials for reviewers |
| **Ads** | App content → Ads | No, app does not contain ads |
| **Content rating** | App content → Content rating | Start questionnaire → fishing/reference app, no violence → usually Everyone |
| **Target audience** | App content → Target audience | 18+ (or 13+ if you prefer; fishing app with accounts) |
| **Data safety** | App content → Data safety | Account email; location (app functionality); purchases via Google Play; no selling of personal data (match privacy policy) |
| **Store listing** | Grow → Main store listing | Short + full description above; 2+ phone screenshots; 512×512 icon; feature graphic 1024×500 |
| **Contact details** | Store settings | Support email + website |

After fixing listing + dashboard, upload a **new AAB** (versionCode 6+) with Billing Library 8.
